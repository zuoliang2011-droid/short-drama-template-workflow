# short-drama-template-workflow（短剧通用模板工作流）

一套可复用的 AI 短剧生产框架：把「关键词 → 全案 → 填模板 → 跑制作」串成标准流水线。

> 对标抖音爆款 AI 短剧方法论（如《非妖哉》2 集获赞 356 万+）。

## 这是什么

一个 WorkBuddy 技能包（skill），输入任意题材关键词 + 现实议题，一次性产出：

- 全季规划表（6 集）
- 本集完整剧本（按六幕结构）
- 分镜表（55~65 镜）
- 角色卡（跨镜一致性）
- 风格锁定提示词
- 下集预告
- 音频层设计 + 制作衔接（即梦 / 可灵 / LibTV 工作流）

## 适用题材

通用框架，**不限定题材**。默认内置「中式志怪 / 老《聊斋》」风格预设，换都市、悬疑、美食、职场等题材时，只替换「风格锁定提示词」一段，其余结构照用。

## 目录结构

```
short-drama-template-workflow/
├── SKILL.md                      # 主技能：创作铁律 + 输出规格
├── README.md                     # 本文件
└── references/
    ├── 通用模板卡.md             # 风格提示词 + 300秒六幕 + 五层转译 + 分镜/角色表头
    └── 音频与制作衔接卡.md       # 配音音色 + 三层音效 + 即梦/可灵/LibTV 流程
```

## 安装

把整个 `short-drama-template-workflow/` 文件夹解压到：

```
~/.workbuddy/skills/short-drama-template-workflow/
```

重启/刷新 WorkBuddy 后即可在对话中通过「关键词：×××」或「写个短剧剧本 / 走制作流程」触发。

## 创作铁律（摘要）

1. 借符号写人：每个核心符号对应一个现实议题隐喻（五层转译）。
2. 风格锁定：禁用网红脸/仙侠古偶油腻感。
3. 结构铁律（300 秒）：钩子15s → 世界建立55s → 异象60s → 抉择与代价80s → 高潮60s → 收尾钩子30s。
4. 节奏曲线：慢→慢→慢→突然加速→戛然而止。
5. 金句三明治：配角 210s 首说，主角结尾变奏复述。
6. 台词零说教：隐喻藏进符号与细节。
7. 连续剧情四原则：主角贯穿一季 / 每集 1 跨集伏笔 / 反派递进 / 议题独立可单集入坑。
8. 合规：恐怖画面用背影/剪影/局部特写替代；片头加虚拟声明。
