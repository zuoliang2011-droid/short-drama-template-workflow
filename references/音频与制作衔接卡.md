# 志怪短剧 · 音频层与制作衔接卡

> 配套 `志怪短剧通用模板卡` 使用。负责「声音怎么设计」+「工具链怎么跑通」。

## 1. 音频层设计

### 1.1 配音音色（按角色填）

| 角色 | 音色设定 | 备注 |
|---|---|---|
| 主角 | ________（如：少女、清冷、叙事感） |  |
| 核心配角 | ________（如：老者、低沉、神秘） | 金句由TA在 210s 说出 |
| 旁白 | ________（民谣体、方言感更佳） | 开场数字+押韵+禁忌感 |

> 原则：音色服务人物弧光；旁白用民谣体，不抢戏。

### 1.2 三层音效结构

| 层 | 作用 | 示例 |
|---|---|---|
| 环境层 | 铺底、定场 | 风声、虫鸣、烛火爆裂、水声 |
| 情绪层 | 推情绪 | 低频嗡鸣、弦乐骤起、心跳 |
| 点睛层 | 名场面打击 | 铜磬、惊堂木、静默（骤停） |

|---|---|---|

| 70–130s | ________（异象显形） | 异象 |
| 210s | 金句落地 + 情绪层起 | 高潮前 |
| 270–300s | ________（收尾钩子音） | 收尾 |

## 2. 制作衔接工作流

### 2.1 工具分工

| 环节 | 工具 | 输入 | 输出 |
|---|---|---|---|
| 分镜/剧本 | WorkBuddy + 模板卡 | 关键词 | 分镜表 + 生图提示词 |
| 生图 | 即梦 | 风格锁定提示词 + 每镜关键词 | 静态帧（多抽卡选 ⭐ 镜） |
| 生视频 | 可灵 / LibTV | 静态帧 + 运镜描述 | 动态镜头 |
| 配音 | TTS（按 1.1 音色） | 台词/旁白文本 | 音频轨 |
| 剪辑合成 | 剪映 / LibTV | 视频+音频+音效 | 成片 |

### 2.2 标准流程（按顺序）

```
1. 关键词 → 跑技能产出全案（剧本+分镜+生图提示词）
2. 即梦：每镜生图，⭐ 重点镜多抽卡，选跨镜一致帧
3. 可灵/LibTV：帧转视频，运镜对齐分镜表「景别·运镜」
4. 配音：按 1.1 音色生成台词+旁白，三层音效按 1.3 点位叠
5. 剪辑：拼镜（严格按六幕秒数），片头加合规声明
6. 自检：过通用卡第 6 节清单 → 导出
```

### 2.3 一致性要点

- 所有生图/视频提示词末尾追加【风格锁定提示词】（见通用卡第 1 节）。
- 角色卡生图提示词固定，跨镜不复述避免脸崩。
- 闪回镜统一「做旧滤镜」标签。
